# Microprocessor vs Microcontroller

| Feature | Microprocessor | Microcontroller |
| --- | --- | --- |
| **Definition** | Just a CPU (the "brain" of the computer). | A small computer on a single chip. |
| **Architecture** | Requires external memory, I/O ports, and other components to function. | All-in-one package containing a CPU, Memory, and I/O ports. |
| **Use Case** | Computers and laptops requiring high processing power. | Smart devices and appliances designed for specific, dedicated tasks. |
| **Examples** | Intel Core i5, AMD Ryzen. | Arduino (ATmega328P), STM32 (used in washing machines, remotes). |
